# 페인포인트 맵 (피쉬본 다이어그램 시각화)

> 원본 분석: [04_pain_points.md](../report/04_pain_points.md) — 본 파일은 동일 내용을 다이어그램 중심으로 재구성한 시각 자료.
> 핵심 질문: **"왜 결제·콘텐츠 도메인의 클라우드 네이티브 플랫폼은 기업마다 복원력·관찰성 성숙도 격차가 크고, 특히 국내 기업은 그 격차를 외부에서 검증하기 어려운가?"**

## 2. MECE 카테고리 ↔ 페인포인트 매핑

```
┌──────────────────────┬──────────────┬─────────────────────────────────────┐
│ 카테고리              │ PP ID        │ 한 줄 요약                            │
├──────────────────────┼──────────────┼─────────────────────────────────────┤
│ A. 기술/아키텍처      │ PP-1, PP-2,  │ 메시 ROI 불명확 / 분산TX 수기처리 /    │
│                       │ PP-6         │ MSA 만능주의 위험                     │
├──────────────────────┼──────────────┼─────────────────────────────────────┤
│ B. 프로세스/거버넌스  │ PP-3         │ 결제 도메인 카오스 실험 보수성         │
├──────────────────────┼──────────────┼─────────────────────────────────────┤
│ C. 조직문화/공시      │ PP-4         │ 국내 포스트모템 공개 문화 부재         │
├──────────────────────┼──────────────┼─────────────────────────────────────┤
│ D. 인프라/환경        │ PP-5         │ 하이브리드 과도기 기술부채 고착        │

4개 카테고리 모두 ≥1개 페인포인트로 커버 (MECE 충족, 누락 없음)
```

## 3. 페인포인트 → 증거 기업 매핑

```
PP-1 (메시 ROI 부재)     ──evidence──▶ Shopify(유일하게 비용 정량화 공개)
PP-2 (분산TX 수기처리)   ──evidence──▶ 카카오페이(3상태 모델, 자동화 미확인)
PP-3 (카오스 보수성)     ──evidence──▶ 카카오페이(결제 도메인 본체만 유일하게 미확인)
PP-4 (포스트모템 부재)   ──evidence──▶ 11번가·카카오페이(비공개) vs 당근마켓(예외적 공개)
PP-5 (하이브리드 부채)   ──evidence──▶ 11번가(Eurekube Operator), 카카오페이증권(3중 클러스터)
PP-6 (MSA 만능주의)      ──evidence──▶ Shopify(모듈러 모놀리스), 당근페이(모노레포) — 반례
```
