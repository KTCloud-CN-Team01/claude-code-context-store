## 3. ポーターの5フォース分析（動画ストリーミング）

### 3-1. 競合の激しさ（中〜高）

```
グローバル競合:
  Netflix, YouTube, Disney+, Amazon Prime Video, Apple TV+, HBO Max
  → 価格競争・コンテンツ獲得競争が激化

日本競合:
  AbemaTV, U-NEXT, dアニメストア, Hulu JP, FOD, NHKオンデマンド
  → 差別化困難・料金競争
```

### 3-2. 新規参入の脅威（低）

- コンテンツ獲得コストが巨額（参入障壁高）
- CDNインフラ整備に数年・数百億円規模が必要
- ブランド認知確立が困難

### 3-3. 代替品の脅威（高）

- TikTok・YouTubeショート（短尺動画の台頭）
- ゲーム・SNSとの時間競合
- 不正視聴・海賊版の問題

### 3-4. 供給者の交渉力（高）

- コンテンツホルダー（映画会社・テレビ局）の交渉力強
- CDNプロバイダーへの依存

### 3-5. 顧客の交渉力（高）

- 月次解約が容易（サブスク疲れ）
- 複数サービス併用 → コスト意識高

## 4. 市場における技術革新の方向性

### 4-1. 現在進行中のトレンド

```
① エッジコンピューティング強化
   目的: バッファリング削減・超低遅延配信
   事例: Cloudflare Stream, AWS CloudFront Functions

② AI/ML活用の深化
   目的: パーソナライズ強化・不正視聴検出・自動字幕
   事例: Netflix推薦システム（機械学習）
   参照: https://netflixtechblog.com/tagged/machine-learning

③ 4K/8K・空間オーディオ対応
   目的: 映像品質向上
   課題: 帯域幅要求が飛躍的に増大

④ アダプティブビットレート（ABR）の高度化
   目的: ネットワーク品質に応じた動的品質調整
   事例: Netflix BOLA, YouTube WISH アルゴリズム
```

### 4-2. インフラへの影響

```
トレンドとインフラ要件の対応:

AIパーソナライズ → GPU対応Kubernetesクラスタ
エッジ配信強化   → マルチリージョンK8s管理（KubeFed等）
ABR高度化        → リアルタイムメトリクス収集基盤
4K対応           → ストレージスケーリング・CDN帯域強化
```

## 5. 市場概観のまとめ

```
動画ストリーミングをドメインに選ぶ理由（再確認）:

✅ 技術的挑戦が最も大きい（スケール・リアルタイム性・グローバル配信）
✅ 公開技術情報が豊富（Netflix Tech Blog 1,000件以上の記事）
✅ カオスエンジニアリングの聖地（Chaos Monkey の発祥）
✅ 国内外でサービス差が明確（AbemaTV vs Netflix の技術格差）
✅ クラウドネイティブ技術の進化と直結した事例が多数
```
